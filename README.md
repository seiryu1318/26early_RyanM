# 수시모집 합불 입력 · 모바일

Google Sheets `편집` 탭의 지원자 정보를 검색하고 Q:U 결과를 입력하는 모바일용 단일 페이지입니다.

- 최초 10건, `더 보기`마다 10건 추가
- 가로 스크롤 없는 카드 목록
- 하단 고정 검색 버튼과 상단 고정 정렬 영역
- 성명·생년월일·수험번호 복사
- 15초 간격으로 열린 검색 결과 동기화
- 배경 이미지가 `index.html`에 내장됨

웹 주소: https://seiryu1318.github.io/26early_RyanM/

서버 코드는 `apps-script` 폴더에 있으며, 비밀번호와 세션 서명키는 저장소가 아닌 Apps Script의 스크립트 속성에서 관리합니다.
